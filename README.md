# Лагерь лесоруба

Браузерная 2D-игра: рубка леса и добыча камня, лагерь с постройками, ночные волны нечисти, боссы, хутора с крестьянами, уровни героя и задания.

Рабочая версия игры живёт как артефакт в Claude. Этот репозиторий — копия кода.

## Как запустить
Открыть `index.html` в браузере. Прогресс хранится в браузере (localStorage).

## Структура
- `index.html` — текущая версия игры (один файл).
- `snapshots/` — сохранённые версии, чтобы можно было откатиться.
